# 한국어 음악 가사 정렬의 검증 범위

현재 검증: 한국어 문자 정규화, 줄 순서, 반복 후렴, 인식 단어 시간 사이의 연주 공백, 누락 시 빈 시간, SRT 검증, 의존성/모델 오류 시 실패 동작. 단위 테스트의 단어 시간은 합성 데이터이며 실제 모델 정확도를 증명하지 않습니다.

WhisperX 3.8.6 배포 패키지의 한국어 기본 CTC 모델 매핑과 load_align_model/align 함수 인수는 확인했습니다. faster-whisper / WhisperX가 일반 음성용 모델이라는 점과 노래 적합성 검증은 별개입니다. GPU는 감지되지 않았고 Hugging Face 연결은 프록시 CONNECT 단계에서 403으로 거부됐습니다. 모델을 우회 다운로드하거나 검증을 비활성화하지 않았습니다. PyTorch/AI 모델 추론, 한국어 실제 Suno 곡의 정렬 성능은 미검증입니다.

## 실제 곡에서 검증하기

권리가 확보된 한국어 곡 3개 이상을 사용합니다: 독창/반주, 반복 후렴 및 10초 이상의 간주, 긴 모음·합창이 포함된 곡을 각각 준비하세요. 사람이 청취해 줄별 시작/끝 시간을 지정한 기준 SRT와 정확한 TXT를 보관합니다. 기준 파일과 음원을 GitHub에 올리지 않습니다.

별도 AI 가상환경과 모델 캐시를 준비한 뒤 UI에서 TXT를 정렬하고, 결과 테이블을 **수정하기 전** JSON으로 저장합니다. 줄 수와 원문·반복 후렴 순서를 비교하고 기준 대비 시작/끝 절대 오차의 중앙값/p95, 0.5초 이내 비율, 미정렬 비율을 측정합니다. 간주에 자막이 발생하는지, 후렴이 앞/뒤 구간으로 잘못 연결되는지 직접 청취하세요. 팀이 요구하는 허용 오차를 먼저 정하고 승인하기 전에는 모델 결과를 제작 품질 보장으로 취급하지 마세요.

자동 정렬 결과를 저장하는 전용 CLI:

```sh
# 이 명령은 AI 가상환경의 Python으로 실행합니다.
SERYU_AI_DEVICE=cpu SERYU_ALIGN_MODEL=/path/to/local/model \
  .venv-ai/bin/python -m seryu.alignment /path/song.wav /path/lyrics.txt /path/new-alignment.json
```

출력 파일은 기존 파일이 없는 새 경로를 사용하세요. 신뢰 지표는 보정된 확률이 아니며 높은 점수라도 실제 타이밍이 틀릴 수 있습니다. AI 검증이 끝날 때까지 결과는 검토 후보로만 사용합니다.
